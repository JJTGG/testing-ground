# Testing Ground

A live, reusable environment for bringing interesting external technologies into controlled experiments, testing them under real conditions, and preserving what we learn.

## Why

Documentation, demos, and claims are useful starting points. They are not the same as testing something ourselves.

Testing Ground exists to turn interesting technologies into actual experiments.

## How it works

Each experiment is brought into a controlled environment, tested, and documented.

The infrastructure is reusable; the experiments are not.

## Principles

- Test real things under real conditions.
- Keep experiments isolated from the core infrastructure.
- Preserve results and observations.
- Prefer evidence over assumptions.
- Start simple and add infrastructure only when experiments prove it is necessary.

## Status

Early development.

The first experiment will be added after the core environment is established.
